
# E-Commerce Sales Analysis using SQL

## Project Overview
This project focuses on designing a relational database and analysing sales data for an e-commerce fashion store using SQL Server.

## Tools & Technologies
- Microsoft SQL Server
- SQL

## Database Design
The project includes four tables:

1. Customers – Customer details and joining dates.
2. Products – Product names, brands, prices and stock.
3. Orders – Customer orders and total amounts.
4. OrderItems – Products purchased in each order.

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- PRIMARY KEY and FOREIGN KEY
- SELECT statements
- JOIN operations
- Aggregate functions (SUM, COUNT)
- GROUP BY and ORDER BY
- SQL Views

## Business Analysis
The project includes queries to:
- Calculate revenue by brand.
- Analyse total units sold by brand.
- Identify customer spending patterns.
- Create a brand sales performance view.
- Create a VIP customer spending view.

## Project Files
- SQLQuery3.sql – Database creation, sample data, analysis queries and views.

## Learning Outcome
Practised relational database design, SQL querying and extracting business insights from sales data.
